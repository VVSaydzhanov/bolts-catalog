# Каталог «Открути болты»

Праздничные модели, которые игра скачивает сама, без обновления в магазине.

- `holidays.json` — список: какие модели, в какие даты, награда, сложность.
- `<id>/<id>.glb` и `<id>/<id>.json` — модель и схема разборки.

Собирается из проекта игры: `python tools/holiday_catalog.py E:/Devolop/bolts-catalog`.
Адрес для игры: https://vvsaydzhanov.github.io/bolts-catalog/holidays.json
